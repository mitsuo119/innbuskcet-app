## 4. コントラスト比（WCAG 1.4.3 AA）

> 前提: 通常テキスト 4.5:1 以上 / 大きい文字（18pt 以上または 14pt bold）3:1 以上 / UI コンポーネント・グラフィック 3:1 以上（WCAG 1.4.11）。

### 4-1. 測定手順

1. ブラウザ DevTools（Chrome）で対象要素を選択し、Styles パネルの色プレビュー横の **コントラスト比** を確認する。
2. もしくは [WebAIM Contrast Checker](https://webaim.org/resources/contrastchecker/) に前景色・背景色を入力。
3. ライト / ダーク両テーマで測定する（`<html data-theme="light">` と `data-theme="dark">` を切替）。
4. ホバー / フォーカス / 選択中（aria-checked=true）の各状態でも測定する。

### 4-2. 測定対象一覧

| #     | 対象                      | ライト | ダーク | 基準    | 結果               |
| ----- | ------------------------- | ------ | ------ | ------- | ------------------ |
| 4-2-a | 本文テキスト vs 背景      |        |        | ≥ 4.5:1 | OK / NG / 該当なし |
| 4-2-b | サブタイトル/補助テキスト |        |        | ≥ 4.5:1 | OK / NG / 該当なし |
| 4-2-c | A/B/C ボタン文字 vs 背景  |        |        | ≥ 4.5:1 | OK / NG / 該当なし |
