## トピック1: なぜこのスプリントは価値があるのか？（Why）

### PO 鈴木の価値提案

> 現状 InBusket は `pnpm dev` / LAN 共有でしか利用できず、佐藤の家族・同僚を含む「任意の端末・任意の場所」での利用は不可能。**ここでインターネット公開（PBI-049）と AdSense 組み込み（PBI-050）を一気に達成しなければ、order007 の「家族・同僚への布教」「運用継続のための小規模収益化」が前進しない**。Sprint010 までで Quick / Deep / Exam の学習サイクルとモバイル最適化は完成しているため、**今が公開の好機**。さらに佐藤フィードバック④起因の PBI-044（Exam 設問別所要時間内訳）を主軸に組み込み、PBI-046 で整備した examAnswers の elapsedMs 拡張を活かして時間配分の自己改善導線を完成させる。

### スプリントゴール（合意）

> **「InBusket をインターネットの公開URLから誰でも利用でき、main push で自動本番反映される基盤を整え、Exam の時間配分自己改善導線を完成させる」**

- **伊藤**: 同意。PBI-049 のホスティング選定 ADR と GitHub Actions ワークフローは経験あり。`vite.config.ts` の `base` 設定と SPA 404 フォールバックを担当する。
- **田中**: 同意。PBI-050 の `<AdSlot />` コンポーネントは環境変数フォールバックが要点。vitest で条件分岐と push 副作用を担保する。PBI-044 の elapsedMs 集計も担当可能。
- **高橋（SM）**: ゴールはステークホルダー（佐藤＝顧客／学習者）にとって「公開」「自動反映」「時間配分自己改善」の単一価値（＝任意端末からの継続利用基盤）に収束しており散逸なし。**承認**。

## トピック3: 選択した作業をどのように完了させるか？（How）

### タスク分解（伊藤主導）

#### PBI-049（GitHub Pages + GitHub Actions CI/CD・3pt）

- **TASK-101**: ホスティング選定 ADR 起票（`project/docs/adr/adr-001-hosting.md`・GitHub Pages 採用根拠 / Vercel・Netlify・Azure SWA 比較） / 担当: 伊藤 / 見積: 2h
- **TASK-102**: `vite.config.ts` の `base` をサブパス（`/<repo>/`）に設定し本番ビルドのみ有効化（開発時は変更なし） / 担当: 伊藤 / 見積: 1h
- **TASK-103**: SPA 404 フォールバック対応（`404.html` を `index.html` コピーで配置するビルド後処理） / 担当: 伊藤 / 見積: 2h
- **TASK-104**: GitHub Actions ワークフロー策定（`.github/workflows/deploy.yml`：main push で `pnpm install → lint → test → build → pnpm audit → deploy`） / 担当: 中村 / 見積: 4h
- **TASK-105**: GitHub Actions PR ゲート策定（lint/test/build/audit のみ実行・deploy しない） / 担当: 中村 / 見積: 2h
- **TASK-106**: `GITHUB_TOKEN` 権限最小化（`permissions:` ブロックで `pages: write` / `id-token: write` 等限定）＋ Secrets 経由運用方針記載 / 担当: 中村 / 見積: 2h
- **TASK-107**: 公開URLでの主要動線（Quick / Deep / Exam の起動・回答・履歴表示）機械検証＋ ads.txt 配置先確認 / 担当: 伊藤 / 見積: 2h

#### PBI-050（AdSense AdSlot コンポーネント・3pt）

- **TASK-201**: `<AdSlot slotId={...} />` React コンポーネント新設（`<ins class="adsbygoogle">` レンダリング後 `useEffect` で `(adsbygoogle=window.adsbygoogle||[]).push({})` を1回だけ呼ぶ） / 担当: 田中 / 見積: 3h
- **TASK-202**: `index.html` の AdSense ローダー（`<script async ...adsbygoogle.js?client=...>`）を `VITE_ADSENSE_CLIENT_ID` 経由で本番ビルド時のみ注入（開発時は注入しない） / 担当: 田中 / 見積: 2h
- **TASK-203**: 環境変数（`VITE_ADSENSE_CLIENT_ID` / `VITE_ADSENSE_SLOT_ID_*`）未設定時の安全フォールバック実装（AdSlot は何もレンダリングしない・例外なし） / 担当: 田中 / 見積: 2h
- **TASK-204**: ヘッダー直下バナー1枠＋ ExamResult 結果画面下部1枠の最小2枠配置・周囲 8px マージン＋罫線でボタン誤タップ防止 / 担当: 田中 / 見積: 3h
- **TASK-205**: vitest 単体テスト（環境変数有無による条件分岐レンダリング・push 副作用1回限定・フォールバック例外なし） / 担当: 山本 / 見積: 3h
- **TASK-206**: 375px 幅で横スクロールなし／ライト・ダーク両テーマ AA／PR に「審査用法務ページは Sprint012 別 PBI」明記 / 担当: 山本 / 見積: 2h

#### PBI-044（Exam 設問別所要時間内訳・2pt）※PBI-046 整備済
