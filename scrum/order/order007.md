- モバイル可読性・誤タップ防止など既存方針との整合

## 追加依頼（2026-05-04 佐藤）

### 背景

`cases.json` の `explanation` フィールドに「パターン〇」という記述がある（例: 「重要顧客の重大クレームは緊急度・重要度ともに最高(パターン1)」）。しかし、現状では**ユーザーがそのパターン番号の意味を理解できない**。また、インバスケット試験そのものを学んでいない人にはアプリの価値が伝わりにくいという課題がある。

### 依頼内容

#### 依頼1: パターン別解説ページの追加

インバスケットの**案件パターン（パターン1〜20）を解説するページ**をWebアプリ内に追加してほしい。

- パターンは緊急度×重要度の組み合わせや案件種別で分類される（全20パターン）
- 解説内容は `ref/chapter08-case-patterns.md` に定義された各パターンを参照すること
- パターン一覧画面と、パターン番号をクリック/タップすると表示される詳細画面を用意する
- 詳細画面では以下を表示すること
  - パターン名（例: 「パターン1: 顧客クレーム」）
  - 特徴・典型的な状況
  - 優先度（緊急度・重要度）の判定理由
  - 対応のポイント・回答の骨格
- `explanation` フィールドの「パターン〇」をクリックすると、該当パターンの解説ページに遷移（またはモーダル表示）できると理想的

**受入基準:**

- [ ] パターン1〜20 の一覧が確認できる画面がある
- [ ] 各パターンの詳細（名称・特徴・対応ポイント）が確認できる
- [ ] `explanation` 内の「パターン〇」テキストからパターン解説へアクセスできる
- [ ] スマートフォン（375px幅）でも問題なく表示される

#### 依頼2: インバスケット解説エリアの追加

アプリのメインに、**インバスケット試験そのものの解説コンテンツ**を充実させてほしい。問題回答機能だけでなく、学習・参照に使えるリファレンスブック的なエリアを設ける。

- 解説内容のベースは `ref/chapter01〜12` の内容を参照すること
- 最低限以下のトピックをカバーすること
  - インバスケットとは何か（`ref/chapter01-what-is-inbasket.md` 参照）
  - 評価の考え方・採点基準（`ref/chapter02-scoring-criteria.md` 参照）
  - 優先順位の付け方・緊急度×重要度マトリクス（`ref/chapter05-prioritization.md` 参照）
  - 案件パターン概説（`ref/chapter08-case-patterns.md` 参照）
- 章立て・ナビゲーション構造でコンテンツを整理する
- 既存の問題回答機能と並列でアクセスできるナビゲーション（タブ or メニュー）を用意する

**受入基準:**

- [ ] インバスケットの基本概念が確認できるページがある
- [ ] 優先順位づけの考え方（緊急度×重要度）を解説するページがある
- [ ] パターン一覧解説ページと統合されている（または導線がある）
- [ ] 既存の問題回答画面から解説エリアへ移動できるナビゲーションがある
- [ ] スマートフォン（375px幅）でも問題なく表示される

### Sprint への組み込みについて

- 本依頼は Sprint011 の既存スコープ（PBI-049, PBI-050）とは別件として、Sprint012 以降のリファインメントでPBIに起票してほしい
- PO（鈴木）にて優先順位を判断すること
- 解説コンテンツのソースは `ref/` フォルダの Markdown ファイルを活用することで、実装工数を削減できると考える

### 依頼内容

目的は、Sprint012 で得た運用知見（A-64/A-65）を PR レベルで再利用できる形にし、同種の手戻りを防ぐこと。

- ページ単位 / 機能単位のどちらを基本にするか判断する
- 判断理由（保守性、影響範囲の見通し、既存構成との整合）を短く残す
- 最小 1 画面で試行導入し、ビルド・表示・既存スタイル崩れの有無を確認する

目的は、今後 PBI-056 / PBI-057 のような画面・解説コンテンツ追加時に、スタイル変更の影響を局所化しやすくすること。

#### 依頼3: インバスケット解説エリア候補の再確認

可能であれば、Sprint012 レビューで継続優先とされた以下も **Sprint013 候補として再確認**してほしい。

- PBI-056: インバスケット解説リファレンスエリア基本構造
- PBI-057: インバスケット解説コンテンツ拡充

ただし、これらは今回の起点そのものではなく、**A-71〜A-73 を主軸整理したうえで余力・優先順位を確認する位置づけ**でよい。
