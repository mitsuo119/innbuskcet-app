# 広告配置ポリシー（AdSense Placement Policy）

最終更新: 2026-05-31（Sprint026 PBI-100 / TASK-100-1）  
責任: PO 鈴木 ／ 実装: 伊藤・山本 ／ レビュー: 渡辺（セキュリティ）

## 1. 目的

Google AdSense の「価値の低い広告枠」「コンテンツのない場所への配置」判定を未然に防ぎ、再申請（PBI-094）以降の安定運用を確立するため、当アプリ全ページに対する**広告掲載可否の判定基準と配置方針**を明文化する。

## 2. 広告掲載最小コンテンツ基準（6条件）

ページ単位で以下 **6 条件をすべて満たす** 場合に限り `AdSlot` を配置可能とする。1 条件でも欠ける場合は配置しない。

| #   | 条件                 | 判定基準                                                                              | 主担当 |
| --- | -------------------- | ------------------------------------------------------------------------------------- | ------ |
| C1  | **本文 600 字以上**  | プリレンダ `<div data-prerender>` 可視テキストが 600 字以上（タグ・空白除外）         | 開発   |
| C2  | **非ナビゲーション** | 一覧・索引・ハブのみで構成されるページではない（記事本文を持つ）                      | 開発   |
| C3  | **独自コンテンツ**   | 自社（運営者）作成の解説・ケース・パターンであり、AIによる量産・他サイト転載ではない  | PO     |
| C4  | **完成済**           | ベータ・未完成・「準備中」ステータスのページではない                                  | PO     |
| C5  | **非法務固定**       | プライバシーポリシー / 利用規約 / お問い合わせ / 運営者情報など定型法務ページではない | PO     |
| C6  | **プリレンダ可視**   | view-source: で本文が hidden / aria-hidden などで隠されていない（PBI-097 適合）       | 開発   |

## 4. 配置パターン

主力 SEO ページ（解説章 / ケース詳細 / パターン詳細）には以下 1 箇所のみ配置する。連続配置・本文中段挿入は禁止。

- **配置場所**: 本文末尾（最後の `<section>` または `<main>` の終端直後）。フッターより上。
- **ラベル**: `広告（コンテンツ下）`
- **className**: `ad-slot--footer`
- **件数**: ページ全体で 1 ユニット

学習トップ（`/`）は既存 2 配置（`ad-slot--header` / `ad-slot--footer`）を継続。

## 5. 実装上の制御

`src/ui/adPolicy.ts` に純関数 `shouldShowAds(pageMeta: AdPageMeta): boolean` を実装し、`AdSlot` の上位レイヤーで判定する（`AdSlot` 自身は環境変数フォールバックのみを担当）。

```ts
export type AdPageKind =
  | "home" // /
  | "reference-chapter" // /reference/chapterXX
  | "case-detail" // /cases/case-XXX
  | "pattern-detail" // /patterns/N
  | "reference-list" // /reference
  | "pattern-list" // /patterns
  | "legal" // /about /terms /terms-of-service /privacy-policy /contact
  | "search"
  | "not-found"
  | "error";

export interface AdPageMeta {
  kind: AdPageKind;
  /** プリレンダ本文文字数（C1 判定。動的ページは省略可で false 判定）。 */
  bodyCharCount?: number;
}
```

`shouldShowAds` の真値条件: `kind` が `home | reference-chapter | case-detail | pattern-detail` のいずれか **かつ** `bodyCharCount` が省略または `>= 600`。それ以外は false。
