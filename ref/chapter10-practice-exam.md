## この章で学ぶこと

- 模範解答と採点のポイント

---

## 演習の進め方

以下の模擬問題は、実際のインバスケット試験を簡略化した形式です。

**演習ルール**:

- 1ケースあたり **15分** で回答する
- タイマーを必ずセットする
- 回答は紙またはテキストエディタに実際に書く（頭の中で考えるだけではNG）
- 書き終えてから模範解答を確認する

---

## 模擬演習 1: 急な顧客トラブル

### 設定

あなたは IT サービス部門の課長として着任して 2 週間目です。前任の佐藤課長は体調不良で急遽退職しました。

### 案件 A: 大口顧客からのクレーム

> 件名: 【至急】システム障害に関するお詫びと対応要請
>
> 宛先: IT サービス課長 殿
> 発信: 営業部 鈴木主任
>
> お疲れ様です。営業部の鈴木です。
> 本日 9 時頃、当社の大口顧客である A 物流株式会社の田中部長から
> 直接電話がありました。
>
> 先週金曜日に納品した在庫管理システムのアップデートにより、
> 一部の倉庫で在庫データに不整合が発生しているとのことです。
> 田中部長は「今週中に改善されなければ契約見直しを検討する」
> と非常にお怒りでした。
>
> 開発担当の山田さんに確認したところ、原因の特定には
> 最低 2 日はかかるとのことです。
> 至急、対応方針をご指示ください。

### 案件 B: 部下の有給休暇申請

> 件名: 有給休暇の申請
>
> 宛先: 課長 殿
> 発信: 山田（開発担当）
>
> お疲れ様です。山田です。
> 来週水曜日〜金曜日（3 日間）の有給休暇を申請いたします。
> 子供の学校行事と通院の予定があります。
> よろしくお願いいたします。

### 案件 C: 社内研修の案内

> 件名: マネジメント研修のご案内
>
> 宛先: 各部門課長 殿
> 発信: 人事部 教育研修課
>
> 来月 15 日（金）に新任管理職向けマネジメント研修を実施します。
> 参加を希望される場合は、今週金曜日までに人事部へご連絡ください。
> ※業務都合で参加できない場合は、次回（3ヶ月後）にご参加いただけます。

---

### 模範解答例

**案件 A の解答（A案件: 最優先）**

```
[判断]
A物流株式会社への対応を最優先とし、本日中に初動対応を実施します。

[理由]
大口顧客からの緊急クレームであり、契約見直しのリスクがあるため、
迅速な対応が不可欠です。

[アクション]
1. 本日午前中に営業部・鈴木主任と電話で詳細を確認します。
2. 山田さんに原因調査の着手を指示し、
   明日中に中間報告を私宛にメールで提出してもらいます。
3. 本日中に私から田中部長にお詫びの電話を入れ、
   今週木曜日までに原因と暫定対策を報告する旨を伝えます。
4. 鈴木主任には営業面でのフォローを依頼します。
5. 金曜日の課内ミーティングで進捗を確認し、
   恒久対策の方針を決定します。
6. 上長（部長）にも本件の概要と対応方針を本日中に報告します。

[関連] 案件Bの山田さんの休暇申請は、本件の調査スケジュールに
影響する可能性があるため、合わせて調整が必要です。
```

**案件 B の解答（B案件: 案件Aとの関連で重要度上昇）**

```
[判断]
有給休暇申請の回答を保留し、山田さんと面談して調整します。

[理由]
本来であれば承認すべきですが、案件AのA物流のシステム障害対応と
時期が重なるため、スケジュールの調整が必要です。

[アクション]
1. 今日中に山田さんと直接話す時間を設け、
   案件Aの状況と休暇のスケジュールを確認します。
2. 原因調査を前倒しで完了できるなら、
   そのまま休暇を承認します。
3. 難しい場合は、3日間のうち1日を 別の日に振り替えられるか
   相談します（本人の事情を尊重した上で）。
4. 代替の調査担当者を確保できるかも併せて検討します。
```

**案件 C の解答（C案件: 通常対応）**

```
参加を希望します。今週中に人事部へ連絡します。
着任2週間で業務の引き継ぎが優先ですが、来月15日であれば
調整可能と判断しました。
```

### 採点のポイント

| 評価軸           | チェック項目                                       | 配点目安 |
| ---------------- | -------------------------------------------------- | -------- |
| 問題発見力       | A物流の問題の深刻さを認識しているか                | ★★★      |
| 意思決定力       | 具体的なアクションと期限を明記しているか           | ★★★      |
| 組織活用力       | 営業部・部長・山田さんの役割を明確に指示しているか | ★★       |
| 洞察力           | 案件AとBの関連に気づいているか                     | ★★★      |
| ヒューマンスキル | 山田さんの事情に配慮しているか                     | ★★       |
| 優先順位付け     | A→B→Cの順で対応しているか                          | ★★       |

## 模擬演習 2: 組織の人間関係トラブル

### 設定

あなたはマーケティング部の課長です。部下は6名です。

### 案件 D: 部下からの相談メール

> 件名: ご相談があります（個人的な内容です）
>
> 宛先: 課長 殿
> 発信: 高橋（入社2年目）
>
> お時間のある時にご相談したいことがあります。
> 最近、先輩の中村さんから業務に関係のない雑用を
> 頻繁に押し付けられており、自分の業務が回らなくなっています。
> 断ると「若手なんだから当たり前だ」と言われます。
> 正直、精神的にもつらいです。
> メールでは詳しく書きづらいので、
> 直接お話しできればと思います。

### 案件 E: 業績報告と目標設定依頼

> 件名: 上半期の業績報告と下半期目標の提出について
>
> 宛先: 各課長 殿
> 発信: 部長
>
> 上半期の業績報告書と下半期の目標設定を、
> 来週月曜日までに提出してください。
> フォーマットは添付の通りです。

---

### 模範解答例

**案件 D の解答（A案件: ハラスメントの可能性）**

```
[判断]
高橋さんとの面談を最優先で本日〜明日中に設定します。

[理由]
「精神的にもつらい」という記述から、パワーハラスメントの
可能性があり、早急な対応が必要です。放置は安全配慮義務の
観点からも問題があります。

[アクション]
1. 本日中に高橋さんに面談日時を連絡します。
   プライバシーに配慮し、会議室を予約します。
2. 面談では、まず高橋さんの話をじっくり聴くことに
   徹します（この段階では中村さんへの指導は早計です）。
3. 事実関係を十分に把握した上で、対応を判断します。
4. パワハラに該当する可能性がある場合は、
   人事部のハラスメント相談窓口に相談します。
5. 本件は部長にも概要を報告し、対応方針を共有します。

[注意点]
・面談前に中村さんに接触しない（先に注意すると相談者が
 特定される恐れがある）
・高橋さんの相談内容は守秘義務を厳守する
```

**案件 E の解答（B案件: 期限あり）**

```
[判断]
来週月曜日の期限に間に合うよう、今週中に作成を進めます。

[アクション]
1. 各メンバーに上半期の実績データを水曜日までに提出して
   もらうよう依頼します。
2. 木〜金曜日で報告書と目標設定を作成します。
3. 下半期目標は部の方針と一致させるため、
   部長に事前確認の打ち合わせを依頼します。
```

## 模擬演習 3: 予算とリソースの判断

### 設定

あなたはシステム開発部の課長です。年度予算の残りは 500 万円です。

### 案件 F: 予算超過の追加開発依頼

> 件名: B プロジェクトの追加機能開発について
>
> 宛先: 課長 殿
> 発信: プロジェクトリーダー 佐々木
>
> B プロジェクトのクライアントから、当初の仕様にない追加機能の
> 要望がありました。対応には約 300 万円の追加費用が見込まれます。
> クライアントは追加費用を負担する意向ですが、
> 納期は当初予定から変更しないでほしいとのことです。
> 現在のチームリソースでは納期を守るのが困難なため、
> 2 名の増員が必要です。
> ご判断をお願いいたします。

### 案件 G: 部下の資格取得支援

> 件名: AWS 認定資格の受験費用について
>
> 宛先: 課長 殿
> 発信: 若手エンジニア 小林
>
> AWS ソリューションアーキテクト・プロフェッショナルの
> 資格取得を目指しています。受験費用 3 万円と
> 教材費 5 万円の部費での負担をお願いできないでしょうか。
> 次のクラウド案件に活かせると考えています。

---

### 模範解答例

**案件 F の解答（A案件）**

```
[判断]
追加開発は条件付きで受け入れる方向で検討します。
ただし、最終判断にはいくつか確認が必要です。

[理由]
クライアントが費用負担する意向であれば売上増につながりますが、
納期維持と品質確保の両立がリスクです。

[アクション]
1. 佐々木PLに以下を確認するよう指示します（明日中に回答）。
   - 追加機能のスコープの詳細と見積りの精度
   - 増員2名の具体的なスキル要件
   - 納期リスクの定量的な評価
2. 費用負担の条件（追加契約の締結）について、
   営業部と法務部に確認します。
3. 増員2名の確保について、他プロジェクトの状況を確認し、
   社内異動または外部委託で対応可能かを検討します。
4. 部長に本件の概要と対応方針を報告し、
   追加契約の承認を上申します。

[リスク対策]
納期遵守が困難と判断した場合は、追加機能の
段階的リリース（フェーズ分け）をクライアントに提案します。
```

**案件 G の解答（C案件）**

```
[判断]
承認します。合計8万円を部費から支出します。

[理由]
次のクラウド案件への直接的な効果が期待でき、
費用対効果は高いと判断しました。
部門の技術力向上にもつながります。

[アクション]
・小林さんに受験・教材の手配を進めてもらいます。
・合格後に部内で知識共有の勉強会を実施してもらう予定です。
```

## 自己採点のやり方

回答を書き終えたら、以下のチェックリストで自己採点してください。

### チェックリスト（各項目 1〜5 点）

| #   | チェック項目                                     | 点数 |
| --- | ------------------------------------------------ | ---- |
| 1   | 優先順位は適切か（A/B/C案件の判断）              | /5   |
| 2   | 判断が明確か（曖昧な「検討」で終わっていないか） | /5   |
| 3   | 5W1Hが入っているか（誰に・何を・いつまでに）     | /5   |
| 4   | 組織を活用しているか（自分で全部やっていないか） | /5   |
| 5   | 案件間の関連に気づいているか                     | /5   |
| 6   | ヒューマンスキルが見えるか（配慮・傾聴の姿勢）   | /5   |
| 7   | フォローアップの記述があるか                     | /5   |
| 8   | すべての案件に回答しているか（白紙がないか）     | /5   |

**合格目安**: 各演習で 30 点以上 / 40 点満点

:::message
**この章のまとめ**: 3つの模擬演習で実際に手を動かして回答を書くことが重要。書いた後に模範解答と比較し、自己採点チェックリストで弱点を見つける。「頭でわかる」と「書ける」は違う。繰り返し実践して、回答パターンを体に染み込ませましょう。
:::
