## この章で学ぶこと

- インバスケットで時間切れにならない配分法

## 時間切れ＝不合格

インバスケットにおいて、時間切れは**最大の敵**です。

20問中10問だけ完璧に書いても、残り10問が白紙なら合格はほぼ不可能です。評価は**全案件の合計点**で決まるため、白紙の案件はそのまま0点です。

> **鉄則: 全案件に何かを書く > 一部の案件を完璧にする**

## 3フェーズ方式

制限時間を3つのフェーズに分けて進めます。ここでは**制限時間90分・案件20問**を例に説明しますが、60分・15問の場合も同じ比率で調整してください。

### Phase 1: 全案件の通読（15分）

**目的**: 全案件の概要を把握し、優先順位をつける

| やること                 | 目安時間        |
| ------------------------ | --------------- |
| 全案件をざっと読む       | 10分（1件30秒） |
| 優先度をA/B/Cに分類      | 3分             |
| 関連案件にマークをつける | 2分             |

この段階では**回答を書きません**。案件用紙の余白に以下のメモだけ残します。

```
案件1: [B] 予算承認 → 単独
案件2: [A] 顧客クレーム → 案件8と関連
案件3: [C] 社内イベント → 単独
案件4: [A] 部下の退職相談 → 案件11と関連
...
```

**優先度の判断基準**（詳しくは次章で解説）:

- **A（高）**: 緊急かつ重要。放置すると大きな損害が出る
- **B（中）**: 重要だが緊急ではない。or 緊急だが重要度は低い
- **C（低）**: 緊急でも重要でもない。定型的な処理で済む

### Phase 2: 回答記入（60分）

**目的**: 全案件に解答を記入する

処理順序は**A → B → C**の順で進めます。

| 案件の優先度 | 1件あたりの目安時間 | 解答量の目安               |
| ------------ | ------------------- | -------------------------- |
| A（5〜7件）  | 4〜5分              | 5〜8行のしっかりした回答   |
| B（8〜10件） | 3分                 | 3〜5行の要点を押さえた回答 |
| C（3〜5件）  | 1〜2分              | 1〜3行の簡潔な回答         |

**重要ルール**: A案件でも1件5分を超えたら次に進んでください。完璧な回答1つより、70点の回答を全案件に書くほうが合計点は高くなります。

### Phase 3: 見直し・補強（15分）

**目的**: 書き漏らしの補填と回答の質を上げる

| やること                                                    |
| ----------------------------------------------------------- |
| 白紙の案件がないか確認 → あれば最低1〜2行書く               |
| A案件の回答を見直し、判断理由や指示の具体性を補強する       |
| 関連案件の相互参照を書き加える（「案件5と合わせて対応」等） |
| 委任先の指示に「期限」「報告方法」が入っているか確認        |

## タイマー管理の実践テクニック

### テクニック 1: 腕時計に目標時刻を書く

試験前に、フェーズごとの目標時刻を計算し、手首やメモ用紙に書いておきます。

```
試験開始: 10:00
Phase 1 終了目標: 10:15
Phase 2 終了目標: 11:15
Phase 3 終了目標: 11:30（試験終了）
```

### テクニック 2: A案件の「タイムリミット」を決める

A案件にのめり込むのを防ぐために、A案件全体の完了目標時刻を決めます。

```
A案件（6件想定）: 10:15 〜 10:45（30分以内）
→ 10:45時点でA案件が残っていても、B案件に移る
→ 残ったA案件はPhase 3で対応
```

### テクニック 3: 「最低限ライン」を先に書く

Phase 2の最初に、**全案件に1行ずつだけ**方針を書いてしまう方法もあります。

```
案件1: 承認する。予算が今期計画の範囲内であるため。
案件2: 顧客に謝罪。田中に対応を指示。
案件3: 参加する方向で日程調整。
...
```

これで全案件が「白紙＝0点」になることを防げます。その後、A案件から順に肉付けしていきます。この方法は**時間管理が苦手な人に特におすすめ**です。

## 残り時間別リカバリー戦略

「やばい、時間がない！」と気づいたときの対処法です。

### 残り30分で半分以上が白紙

**対応**: 全白紙案件に1〜2行の方針だけ書く。A案件のみ3行書く。

### 残り15分で3〜5件が白紙

**対応**: 白紙案件に最低1行書く。既存の回答に判断理由を1文足す。

### 残り5分で白紙がある

**対応**: とにかく書く。「○○を確認の上、部下に対応を指示する」の1文だけでも白紙よりはるかにマシ。

## 時間配分の練習方法

本番で時間配分が崩れないよう、事前に以下の練習をしましょう。

1. **模擬問題をタイマー付きで解く**（第10章で提供）
2. **Phase 1を繰り返し練習**する（通読→分類の15分を5回以上練習）
3. **1件3分で書く練習**をする（キッチンタイマーで3分計って1件書く）

:::message
**この章のまとめ**: 時間配分は「15分：60分：15分」の3フェーズ方式。全案件に書くことを最優先し、1件に5分以上かけない。白紙＝0点を絶対に避ける。これだけ守れば、時間切れで不合格になることはありません。
:::
