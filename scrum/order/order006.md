## 依頼概要

Sprint009 で `window.confirm`/`alert` の主要 3 動線を内製 ConfirmDialog に完全置換し、Exam の中断・再開（sessionStorage + 3 択ダイアログ）と模範解答 40 件整備が完了。学習サイクル（Quick → Deep → Exam → ExamResultView → Deep 継続）と主要ダイアログ体験は一貫化された。
ただし**実利用シーンの中心が「通勤時のスマホ片手」に移っている**ため、Sprint010 では **モバイルブラウザ最適化（PBI-045）を主軸**に据え、同時に Sprint009 で残った 2 つのトレードオフ（**PBI-046 examAnswers 完全保存 / PBI-047 ConfirmDialog モバイル幅検証**）を解消する。

## 背景・目的

- Sprint009 レビュー佐藤④で **PBI-046（Exam answers 完全保存）の早急な実装**を強く要望。現状は `answeredIds` のみ保存・`judgement='correct'` スタブ復元のため、再開後の振り返りが**不正確**。学習価値の毀損に直結するため Sprint010 で必ず解消する（A-54）。
- Sprint009 レビュー佐藤⑤で **PBI-045（モバイルブラウザ最適化）を Sprint010 で取り組んでほしい**と明言。通勤・隙間時間の主用途デバイスは iPhone / Android であり、これが満たされないと「毎日継続」の前提が崩れる。
- ConfirmDialog のモバイル幅レイアウト検証（PBI-047）は PBI-045 と一体で進めるのが自然（A-55）。`pr_checklist.md` §6 にモバイル幅（375px）チェック観点を追加する運用検証も兼ねる。
- Sprint009 レトロ A-56 で `a11y_checklist.md` に「ダイアログ系 UI の初期フォーカス対象妥当性確認」観点を追加することが合意済。Sprint010 リファインメントで反映し、PBI-047 検証で初運用する。
- ベロシティは 9 スプリント平均 9.22pt、5 スプリント連続「計画 = 実績」着地。culture 項目 6 に従い **6〜9pt**（A-57）が指針。新領域（モバイル実機確認）が入るため、詰め込みは禁物。

## Sprint010 で達成したいこと（佐藤の優先方針）

### 最優先：通勤シーンで「毎日継続」できるモバイル体験を仕上げる

1. **PBI-045（2pt / High）**: 375px 幅で横スクロールなし・主要操作 44px 以上タップ領域・ソフトキーボード時の動線復帰・iPhone Safari / Android Chrome 現行主要版で手動確認。
   - **絶対に外せない**。これがないと通勤時の利用が成立しない。
2. **PBI-047（1pt / Low）**: PBI-045 のスコープ内で ConfirmDialog の 375px レイアウト・ソフトキーボード被り・両テーマ AA を検証。`a11y_checklist.md` 初期フォーカス観点（A-56）も初運用。

### 同等優先：Exam 再開の正確性を担保する

3. **PBI-046（2pt / Medium）**: examAnswers 配列全体（answer.id / judgement / userInput 等）を sessionStorage に保存し、再開後の正答率・所要時間・優先度別正答数を**中断前と一致**させる。`saveExamProgress` のスキーマ検証を拡張（DoD §10-3）。
   - PBI-041 のトレードオフ（answers スタブ復元）を解消する**約束した実装**。Sprint010 で必ず取り切る。

### 余力次第（合計 6〜9pt 範囲で 1〜4pt 加算）

4. PBI-031（1pt）/ PBI-032（1pt）: 軽量で他 PBI と独立。
5. PBI-043（3pt / Medium）: ExamResultView 強化。PBI-046 と同じ ExamResultView 周辺で作業範囲が重なるため、**まとめて取ると効率的**。
6. PBI-044（2pt / Low）: 同上。設問別所要時間 sessionStorage 拡張があるため §10-3 観点で PBI-046 とテーマが揃う。
7. PBI-025（3pt）/ PBI-026（2pt）: 弱点可視化系。Sprint010 主軸 5pt が確定した後の優先度は低めでよい。

## 非機能・制約

- 技術構成は pnpm + Vite + React + TypeScript を維持
- ローカルブラウザ単独で完結（認証・DB・API は引き続きスコープ外）
- 自由記述本文は引き続き**セッション内のみ保持**（永続化対象は学習スタイル設定 / Exam 進捗 / examAnswers のみ）
- examAnswers の sessionStorage 保存（PBI-046）は **DoD §10-3 スキーマ整合性検証**を必須（既存 examProgress に準拠）
- モバイル実機確認（PBI-045 / PBI-047）は iPhone Safari / Android Chrome の**現行主要版**を対象。古い OS / ブラウザはスコープ外
- ネイティブモバイルアプリ実装はスコープ外を維持
- 助っ人（山本・中村）は引き続き handoff 運用
