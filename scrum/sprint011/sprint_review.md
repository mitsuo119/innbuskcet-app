## 5. 環境変化の共有

- 市場: 公開URL運用開始により「家族・同僚への共有 → 利用フィードバック」サイクルが Sprint012 以降に開始可能。佐藤のモバイル比率 7 割は維持。
- 技術: GitHub Pages サブパス（`/<repo>/`）公開で SPA 直リンクの 404 フォールバックが本番ビルド時のみ必要となる前提が確定。`copy-404.mjs` で恒久対応済。
- 規約: AdSense 実 ID（client/slot）は **Sprint012 で PO 経由で佐藤から取得し GitHub Secrets へ投入**する運用を確定（コミット禁止／DoD §5-2）。`index.html` へのローダー `<script>` 追加（本番ビルド時のみ）も Sprint012 で対応。
- 依存: vitest 4 + Vite 8 では `import.meta.env` の動的書換が静的置換の影響でテストに反映されない事象を確認。**props 経由検証**で機能要件を網羅できるためチームナレッジ化（テスト規律として記録）。
