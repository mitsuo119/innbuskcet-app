## 2. 完了PBIのデモ要約（伊藤・田中）

### PBI-061: 解説リファレンスから chapter 表記と参照元パス表示を撤去（1pt）

- `referenceData.ts` の章タイトルを利用者向け自然言語に置換（対応元情報はコメントとして保持）
- `ReferencePage` から `chapterXX` キッカー表示・`ref/...` パス表示・参照元 dl を撤去
- 既存テスト（`ReferencePage.test.tsx` / `Router.reference.test.tsx`）を新表記に追従更新

### PBI-062: 解説リファレンスエリアの UX 向上（3pt）

- 章詳細に「前の章 / 章一覧へ戻る / 次の章」の3導線を追加（端章は `<span role="link" aria-disabled="true">` で無効化）
- タイポ・余白・カード境界・章番号バッジ＋タイトル構成で可読性を改善
- スタイルは `ReferencePage.css` に局所化し PBI-060 の CSS 分割方針を維持
- vitest +5 ケース（端境界・aria 属性・インライン style 不在の不変条件）

### PBI-063: 問題回答画面と結果画面のデザイン/UX 向上（3pt）

- QuickView / DeepView / ExamView 共通の `case-view` / `answer-buttons` / `actions` で余白・タイポ・状態強調（focus/hover/active）・カード境界を整理
- ExplanationView / FeedbackView / ExamResultView 詳細パネルまで対象を広げ、未定義トークン（`--color-accent` フォールバック）を `--color-primary` / `--color-focus-ring` に統一
- 375px でタップ領域 44px+（answer-buttons 64px / actions・retry・detail 各 44px）、両テーマで AA 維持を実測確認
- vitest +12 ケース（AnswerButtons / CaseView / ExplanationView の不変条件・DoD §10-2 検証）
