顧客: 佐藤（上長代行で作成）

## 依頼概要

固定ページ（運営者情報 / プライバシーポリシー / 利用規約系）に記載されている「**最終更新日**」が **本日（2026年5月16日）より未来の日付**になっており、明らかに誤り。**全該当ページの最終更新日を本日（2026年5月16日）に修正**してほしい。

AdSense 再申請（order014）の主軸テーマと並行する**軽微なコンテンツ修正**として、最速で取り込んでほしい。

## 背景

- 本日: **2026年5月16日**。
- order014 の AdSense 審査再申請対応で、運営者情報（/about）・プライバシーポリシー（/privacy-policy）・利用規約（/terms, /terms-of-service）を整備した際に、最終更新日に**未来日**を入れてしまっている。
- これは AdSense / SEO レビュアー視点で「日付の整合性が取れていない（信頼性シグナルの毀損）」となり得るため、再申請までに必ず是正する必要がある。

### 補足：他に最終更新日表記があるか

- 「最終更新日」「Last Updated」「最終改定」「制定日」「施行日」を `project/front/` 配下全体で検索。
- `legal-updated` クラスは Case/Pattern 等の他ページでも別用途（カテゴリ表示等）に流用されているが、**日付を表示しているのは上表の 4 ファイルのみ**。
- `dist/` 配下の build 成果物にも同じ未来日が焼き込まれているが、再ビルドで自動更新されるため**ソース修正のみで OK**（dist は触らない）。
- README / docs / scrum 配下のドキュメントには「最終更新日」は記載されていない（運用ガイド系の `seo_operations.md` 等にも該当なし）。

## 想定の修正方針

1. **本日（2026年5月16日）に統一**して 4 ファイルとも書き換える。
   - 上表の置換のみ。本文・JSON-LD・metadata 等は触らない。
2. **テストへの影響**: 日付文字列を assert しているテストは存在しないことを確認済み（`2026年10月8日` / `2026年7月15日` の grep hit はソース 4 ファイル + dist のみ）。Vitest スナップショットへの影響可能性のみ最終確認のこと。
3. **DoD**:
   - vitest / tsc / eslint オールグリーン
   - `pnpm build` 成功（dist の `legal-updated` が `2026年5月16日` に更新されること）
   - PR で 4 行の差分のみ（最小変更）
4. **PBI 起票単位**: 軽微・ノーリスクのため**単一 PBI（1pt）**で十分。AdSense 再申請の依存タスクとして優先取り込み。

## 注意点 / 追加論点（チームで判断）

- 利用規約が `Terms.tsx`（/terms：簡易版）と `TermsOfService.tsx`（/terms-of-service：条文版）の **2 本立て**になっている。今回のスコープは「日付修正のみ」。一本化の要否は別 PBI とすること（本依頼では対応不要）。
- 今後「実体改定がない月次の最終更新日空更新」はかえって信頼性を損なうので、**実改定があった日付のみ更新する**という運用ルールを `seo_operations.md` あたりに後日追記しておくことを推奨（本依頼スコープ外、メモのみ）。
