# AdSense コンテンツ改訂記録

確認日: 2026-09-07。対象: inbasket-app.com とローカル実装。コンテンツ改訂と依存更新のローカル検証を記録する。AdSenseへの再申請は別途実施する。

## 判断と改訂

Googleの通知は「有用性の低いコンテンツ」であり、個別の不合格原因は非公開。以下はソースと公開画面で確認できた改善点で、Googleが原因と特定した項目ではない。

| 確認した問題 | 改訂 |
| --- | --- |
| トップが機能の長い紹介で、演習が下へ押し出される | 5案件の前提・着手順・回答比較・条件変更を扱う独自記事に変更。演習の後に配置 |
| 章別URLでも全12章を描画し、指定章へスクロールするだけ | 各詳細URLでは該当章の本文だけを表示。全12章で他の章の混入を防ぐ回帰テストを追加 |
| 配点・採点者の期待を裏付けなく断定 | 採点章を比較教材へ改訂。20パターンの採点者視点を自己点検へ変更 |
| 不具合対応の正式回答日を未調査で確約、匿名性の保証、休暇当日の報告要求 | 顧客不具合・匿名相談・休暇申請のケースと対応パターンを見直し |
| 語句照合処理を「AI評価」「優秀」と表示 | 語句・形式の自動チェックとして限界と確認先を表示 |
| 記述チェックを押しても回答確定まで結果が見えない | 押した直後に結果を表示。回答後も重複せず、次問でリセット |
| 問い合わせがGitHubトップへ遷移 | ユーザー指定の公開Issuesへ修正。公開投稿とアカウントの必要性を明示 |
| AI開発上の役割と運営主体が曖昧 | 管理アカウント、AI利用、非公式教材の位置付けを開示。資格・監修実績は創作しない |
| Cookieとブラウザ内保存を混同 | 広告・サイト配信・学習データ・問い合わせを区別して説明 |
| 固定ページの静的HTMLが本文ではなく紹介文のみ | 運営・問い合わせ・プライバシー・トップ・採点章を共通データ化し、画面と静的HTMLを一致 |
| トップの操作前に広告、模試でも広告枠あり | 通常学習の記事下1枠のみ。模試・結果・問題なしでは非表示 |

## 検証

- 集中テスト: 記事・固定ページ・採点章の全段落一致、全40詳細ページの前提、参照リンク、重点解説、広告配置を確認済み。
- プリレンダ: 504テスト成功、改訂本文の7スナップショットを更新。
- 全体テスト: **64ファイル・1,253件成功**。jsdomのリンク遷移未実装ログは残るが、テスト失敗なし。
- ESLint・TypeScript・ビルド成功。`https://inbasket-app.com/` を設定して60ルート生成。バンドル500kB超の警告あり。差分の空白チェック成功。
- 最終ビルドのルート検証: **previewで43ルート成功・失敗0**。[アウトカム検証レポート](./outcome_verification_report.md) に記録。本番の検証結果ではない。
- ブラウザ: 1280px／375pxで改訂した主要ページの本文と横はみ出しを確認。記述チェックの即時表示、回答、次問、記事へのページ内移動が動作。採点章の本文が1章だけであることを両幅で確認。スクリーンショットでスマホの見出し・本文の折り返しを確認。
- Lighthouse 13.4.1（ローカルトップ・モバイル・広告ID未設定）: Performance **77**／Accessibility **100**／Best Practices **100**／SEO **100**。JSONのruntimeError・runWarningsはなし。CLI終了時は一時フォルダ削除がEPERMで失敗したため、保存された計測JSONから集計。ラベルとアクセシブル名の不一致というスコア外指摘は残る。
- 初回の `pnpm audit --audit-level high` はHigh 15件・Moderate 5件で失敗したが、追加依頼で修正し**既知の脆弱性0件**を確認した。[依存更新記録](./dependency_security_update_2026-09-07.md) を参照。上記Lighthouse値は依存更新前の計測。
- 案件ID・件数・正答分類・JSON列構成は変更なし。ケースの追加・削除は行っていない。
- 外部確認: 公開トップはブラウザで表示。取得ツールでは403のため、一般利用者の到達不能とは断定しない。指定Issuesページは公開で閲覧できた。投稿の送信はしていない。

## 公開後に残る確認

本番への反映、全ルートの到達・新本文、広告管理画面の設定、対象地域の認定CMP・同意、ads.txt、ポリシーセンター、読者による内容確認は別途確認する。依存関係のHigh指摘は解消済み。コード検証だけでサイト全体のポリシー遵守や合格を保証しない。

同じ文字列がないことは、意味上の重複がない証明ではない。他の章・解説にも一般化された助言があるため、継続して実際の読者の疑問に答えているか確認する。出典を添えた公的サイトは制度の確認先であり、本教材の公式監修や個別答案の正解を裏付けるものではない。
