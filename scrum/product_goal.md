# プロダクトゴール

## プロダクト名

**InBusket（インバスケット学習Webアプリ）**

## プロダクトビジョン

忙しいビジネスパーソンが、隙間時間にブラウザだけで気軽にインバスケット思考（限られた時間で複数案件の優先順位を判断するスキル）を反復学習でき、判断の「型」を自然に身につけられる学習体験を提供する。

## プロダクトゴール

> プロダクトゴールはプロダクトバックログに含まれ、残りのプロダクトバックログはプロダクトゴールを実現する「何を」を定義するために出現する。
> — スクラムガイド 2020

### 現在のプロダクトゴール

**「ローカル稼働のWebアプリで、案件をランダム出題し、A/B/C の優先度回答に対し正解と理由を即時提示する『最小の学習サイクル』を実現する」**

#### ゴール達成の条件

1. ブラウザでアプリを開くと、用意された案件から1件がランダム出題される
2. ユーザは A（高）/ B（中）/ C（低）で回答でき、回答後に正解と理由（解説）が表示される
3. 「次の問題」で別案件が出題され、隙間時間（数分）でストレスなく操作できる

## ステークホルダー

| 名前       | 役割               | 関心事項                                       |
| ---------- | ------------------ | ---------------------------------------------- |
| 佐藤       | 顧客（学習者）     | 隙間時間で気軽にインバスケット学習ができること |
| 鈴木       | プロダクトオーナー | 価値の高い学習体験の早期提供                   |
| 開発チーム | 開発者             | シンプルかつ将来モバイル化を見据えた構成       |

## 成功指標

- 1案件あたりの操作完了時間が概ね1〜2分以内
- 出題→回答→解説→次問のサイクルがエラーなく繰り返せる
- 案件データの追加が、コード改修なしに JSON 編集のみで可能
