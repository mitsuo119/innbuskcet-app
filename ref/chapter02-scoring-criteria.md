## この章で学ぶこと

- 公式の採点基準と教材独自の自己点検を区別する
- 答案の具体的な一文を根拠に振り返る
- 自動チェックを合否予測に使わない

---

## 公開本文の管理

2026-09-07改訂。公開本文は [scoringGuide.json](../project/front/src/data/scoringGuide.json) に集約し、React画面とプリレンダで同じ内容を使用する。

旧稿の「意思決定力が最も高配点」「特定行動で0点」といった裏付けのない断定は撤回した。6つの観点は本教材独自の自己点検であり、実際の配点や合格ラインではない。

## 自己点検の要点

| 観点 | 答案で確認すること |
| --- | --- |
| 問題発見力 | 案件の関連性や確認すべき問題を挙げる |
| 問題分析力 | 事実・未確認情報・仮定を分ける |
| 意思決定力 | 今決めることと確認後に決めることを分ける |
| 洞察力 | 想定どおり進まない場合の次の手を残す |
| 組織活用力 | 担当・成果物・期限・報告先を明示する |
| ヒューマンスキル | 相手の立場と情報の共有範囲に配慮する |

公開本文には、顧客クレームの答案比較、自己点検の手順、語句照合による自動チェックの限界、関連演習へのリンクを含む。
