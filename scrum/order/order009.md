# 依頼事項メモ order009

## 依頼者

顧客: 佐藤

## 依頼概要

ユーザー満足度と集客力の向上を目的に、

1. 学習問題数の拡充、2) SEO対策の強化 を優先的に進めたい。

## 背景

- 現状は学習体験の質が上がってきた一方、継続利用の観点で「問題の量」と「発見されやすさ（SEO）」をさらに強化したい。
- 問題数が増えるほど、反復学習・弱点補強・モード別学習の満足度が上がる。
- SEOの基盤を整備することで、新規ユーザー流入の増加と既存コンテンツ価値の最大化を狙いたい。

## 要求事項

### 1. コンテンツ拡充（問題データ増量）

- 既存ケースデータを計画的に増量する（追加方針・件数目標・品質基準を明確化）。
- 問題の偏り（難易度・テーマ・優先度カテゴリ）を抑え、学習用途として実用的な分布を維持する。
- 追加問題は既存導線（Quick / Deep / Exam など）で利用可能にする。

### 2. 構造化データの追加/改善

- 検索エンジンがページ内容を理解しやすいよう、主要ページに構造化データを追加または改善する。
- コンテンツ種別に応じて、適切なスキーマ定義（例: WebSite, BreadcrumbList, FAQPage など）を検討する。

### 3. 内部リンク導線強化

- 学習導線とSEO導線を両立する内部リンク設計に改善する。
- 主要ページ間（トップ、解説、パターン、学習モード関連）の回遊を強化し、関連ページへ自然に遷移できるようにする。

### 4. メタ情報とサイトマップ整合性強化

- title / description / OGP 等のメタ情報をページ役割に応じて見直し、重複や不足を解消する。
- サイトマップと実ページ構成の整合を取り、更新運用（新規ページ追加時の反映ルール）を明確にする。

## 受入イメージ

- 問題データが増量され、学習時に「問題のバリエーションが十分」と感じられる。
- 主要ページで構造化データが適用され、技術的な不備がない状態で確認できる。
- 関連ページへの内部リンクが強化され、ユーザーが迷わず回遊できる。
- メタ情報とサイトマップの整合が取れており、SEO運用の基本が継続可能な形で整備されている。

## 優先度

- 優先度: High
- 依頼方針: 次スプリントのリファインメント対象として優先的に分割・見積もりを実施

## リファインメント用メモ（次ステップで分割したい単位）

- 候補A: 問題データ増量（件数目標・分布基準・受入チェックを含む）
- 候補B: 構造化データ整備（対象ページ定義・検証観点）
- 候補C: 内部リンク改善（導線マップ・主要遷移の改善）
- 候補D: メタ情報/サイトマップ整備（ページ単位の整合チェックと更新運用）

上記A〜Dを独立PBIとして分割可能な粒度で、PO/開発者にて見積もり・優先順位付けを実施したい。
