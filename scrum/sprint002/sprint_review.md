1. `pnpm dev` 起動 → 出題画面で A/B/C キーで即時回答、Enter で次問へ
2. 画面右上のカウンタで「正答/出題」がリアルタイム加算（リロードで0/0にリセット）
3. 解説画面の「もう一度」押下で同案件再出題、カウンタは加算されない
4. `cases.json` 32件（A:12 / B:12 / C:8、各25%以上）から直前案件を除外しランダム出題
5. ディレクトリ構成 `src/ui` / `src/domain` / `src/data` 分離をエディタで提示、UI層は loader 経由でのみ JSON を参照
6. `pnpm audit` 実演 → `No known vulnerabilities found`（vite 5→8 / vitest 2→4 メジャー更新で moderate 解消）

## ステークホルダーフィードバック要約（佐藤）

- **機能性**: ショートカット・カウンタ・「もう一度」いずれも要求どおり動作。学習サイクルがさらに滑らかになった。
- **ユーザビリティ**: キーボードのみで全操作完結、focus 可視で迷わない。スマホ幅でも崩れず合格点。
- **ビジネス価値**: 「隙間時間に手応えを得る」目的を強化できた。同僚への共有を本格検討したい。
- **改善提案**:
  1. **直近の正誤履歴を画面で確認したい**（直近10問程度、永続化は不要）
  2. **案件パターンの完全網羅**（chapter08 の20パターン全てを最低1件以上カバー、件数は40件規模へ）
  3. **難易度別出題モード**（A/B/C のうち1種類に絞って練習したい時がある）
  4. ダーク/ライト切替は引き続き低優先で OK（夜の学習で軽くあると嬉しい程度）
  5. PBI-013 で C 比率がやや低い（25%）→ 次回拡充時にバランス再調整を希望
