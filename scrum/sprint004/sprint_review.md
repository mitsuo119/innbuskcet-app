## インクリメントのデモと検査（伊藤・田中）

ライト/ダーク両テーマで実機デモを実施。

### PBI-019 ダーク/ライトテーマ切替（2pt）

- 画面右上 `ThemeToggle`（`role="switch"` / `aria-checked` / `aria-label`）で切替。Tab→Space/Enter のキーボード操作で完結。
- `:root[data-theme="light"|"dark"]` の CSS Custom Properties（17 種類）でテーマトークン化。コントラスト比はライト本文 12.6:1 / ダーク本文 14.5:1（WCAG AA 4.5:1 を上回る）。
- A/B/C 表示は色＋記号（◎/○/△）＋名称（最優先/中優先/低優先）の 3 冗長化（佐藤フィードバック4 反映）。
- localStorage（キー `inbusket.theme`）永続化、リロード後復元、try/catch でプライベートモード安全。切替時にカウンタ・履歴・モード非リセット。

### PBI-020 履歴表示件数の選択 10/20（1pt）

- 履歴領域上部のラジオボタン（`<fieldset>`+`<legend>`）で 10/20 切替。
- セッション内のみ保持、リロードで 10件に戻る。20→10 縮小時は `trimHistory` で末尾優先補正。
- 切替時にカウンタ・モードは非初期化。キーボード操作（Tab→Space）で完結。

### PBI-021 モード別正答率の集計表示（2pt）

- `ScoreCounter` がモード（全件/A/B/C）に応じて「正答/出題（正答率%）」表示。`addModeScore` で全モード独立集計。
- 0 件モードは `(-)` 表示で除算エラー回避。`aria-live="polite"` でモード名・正答率を SR 通知。
- リロードで初期化（PBI-018 と整合）。

### PBI-022 履歴コントラスト見直し WCAG AA（1pt）

- 履歴セル専用変数 5 種を追加し、ライト/ダーク双方でコントラスト比 8.1:1〜11.2:1 を実測（WCAG AA 4.5:1 を大幅に上回る）。
- ○/× 記号 ＋ A/B/C 文字 ＋ `aria-label` の 3 冗長化を維持（色非依存）。PBI-019 のテーマトークンと統合され二重メンテなし。

## ステークホルダーフィードバック（佐藤 顧客）

### 機能性

- ダーク/ライト切替が一瞬で反映され、リロードしても保持されるのは想定通り。夜間の学習が目に楽になった。
- モード別正答率は「自分は B が弱い」と一目で分かり、弱点認識が速くなる。

### ユーザビリティ

- A/B/C ボタンの「◎/○/△＋名称（最優先/中優先/低優先）」併記は秀逸。**Sprint003 までで最大の改善**で、色覚多様性のある同僚にも安心して勧められる。
- 履歴 10/20 切替は「短時間集中なら 10、振り返り重視なら 20」の使い分けができてよい。

### ビジネス価値（昇進試験合格に役立つか）

- 「同僚共有に耐える完成度」のゴールは達成。**社内勉強会のデモに耐える**水準。
- ただし**昇進試験合格直結**という観点では、まだ「優先度選択クイズ」止まり。本番試験は記述（判断・理由・アクション）と時間制限（90分20問）が本丸。Sprint005 以降の PBI-023〜027 を急ぎたい。

### 改善提案

1. **(継続)** PBI-023（3ブロック記述）と PBI-024（模範回答骨格との比較）を Sprint005 で最優先にしてほしい。chapter09 の合格答案の型を反復したい。
