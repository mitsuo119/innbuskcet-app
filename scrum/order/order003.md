## Sprint003 スプリントゴール案

> 学習者個人の到達度を可視化し、苦手領域を反復できる学習体験へ進化させる（履歴・パターン網羅・難易度別）。

## 計画方針

- 計画ポイントは 7〜11pt（A-9）
- コア候補は PBI-016 + PBI-017 + PBI-018（計7pt）
- PBI-019 はバッファが十分な場合のみ差し込み検討（A-6基準を満たす場合のみ）
- Sprint003 から DoD §9（アクセシビリティ）を必須適用

## 非機能・制約

- 技術構成は pnpm + Vite + React + TypeScript を維持
- ローカルブラウザ単独で完結（認証・DB・APIは引き続きスコープ外）
- 助っ人（山本・中村）はプランニング/レビュー/レトロ不参加のため、handoff 運用を前提にする

## スコープ外（現時点）

- ユーザ認証、成績の永続保存、ランキング機能
- AI案件自動生成
- ネイティブモバイルアプリ実装

## 確認事項（Sprint003 リファインメント/プランニングで合意）

1. PBI-017 の「20パターン完全網羅」をどの粒度で証跡化するか（マッピング表の置き場所）
2. PBI-017 の C 比率目標（各30%以上）を受入基準として固定してよいか
3. PBI-018 のモード切替時に履歴/カウンタをどう扱うか（初期化の一貫性）
4. PBI-019 は今回スコープに含めるか、次スプリント送りか
5. A-6/A-7/A-8 を Sprint003 開始時にどのファイルへ正式反映するか

## 受入のイメージ（佐藤目線）

- 学習中に「直近10問の正誤履歴」で弱点が見える
- A問題だけ/B問題だけの反復練習ができる
- 案件は40件以上で、chapter08 の20パターンが偏りなく学べる
- 既存の快適さ（ショートカット、再出題、レスポンシブ、a11y）を維持したまま機能追加される
