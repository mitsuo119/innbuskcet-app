## トピック1: なぜこのスプリントは価値があるのか？（Why）

### PO鈴木からの価値提案

Sprint026 で AdSense 審査落ち 4 直接原因（クローキング/薄プリレンダ/一覧欠落/広告配置）を全て根治し、`inbasket-app.com` カスタムドメインで本番公開も完了。**ところが本番公開直後の実機レビューで致命的不具合を発見**：

- サーバ返却の **静的HTML（プリレンダ）は良好**（chapter01 で 1,938 字が `hidden` 無しで可視出力 / view-source 確認済）。
- しかし **JS hydration 完了後、トップ以外の全URL（/about/, /privacy-policy/, /reference/, /reference/chapterNN/, /cases/, /cases/:id/, /patterns/, /patterns/:id/）が NotFound コンポーネントに置換**。
- 原因は GitHub Pages カスタムドメインがディレクトリ型URLを **末尾スラッシュ付き** にリダイレクトする一方、`project/front/src/Router.tsx#parsePathname()` が**末尾スラッシュなし前提の完全一致**でしか判定していないため、本番で全件 NotFound にフォールバック。
- Googlebot 視点ではトップ以外の有効ページがゼロ＝ AdSense 再申請しても確実に「有用性の低いコンテンツ」で落ちる。**Sprint024〜026 の SEO/プリレンダ/コンテンツ強化の成果がすべて無効化されている**。

Sprint027 は **「本番でGooglebotが各コンテンツページを正しく認識できる状態（JS実行後も404化しない）を実現し、AdSense再申請の前提を整える」** を単一目的とする。この根治により Sprint026 の成果が初めて本番で機能し、PBI-094（再申請）へ物理的に進める状態に到達する。

### スプリントゴール（合意済）
