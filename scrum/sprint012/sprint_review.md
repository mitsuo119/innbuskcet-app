## 2. インクリメントのデモ・説明（伊藤・田中）

### PBI-051: AdSense審査用法務ページ（PrivacyPolicy / TermsOfService / Contact）

- `PrivacyPolicy.tsx` で AdSense・Cookie・データ収集方針を明記
- 3ページへの導線（戻る導線含む）を整備し、キーボード到達を確保
- `dangerouslySetInnerHTML` 不使用でXSSリスクを抑制
- 375px幅、ライト/ダークテーマ表示を確認

### PBI-052: AdSenseローダー注入・環境変数管理

- `vite.config.ts` に本番ビルド時のみ動作する AdSense ローダー注入処理を実装
  - `VITE_ADSENSE_CLIENT_ID` がある場合のみ `<script async ...adsbygoogle.js?client=...>` を注入
  - 開発・テスト時は注入しない設計
- `AdSlot.tsx` は環境変数未設定時 `null` を返す安全フォールバック
- `.env.example` と GitHub Secrets 運用を整備し、シークレットのコード直書きを回避
- `deploy.yml` の build で Secrets 注入、DoD 5-2（シークレット管理）に適合

### PBI-055: パターン別解説ページ（一覧・詳細・explanationリンク）

- `patternData.ts` を唯一の定義源としてパターン1〜20を実装
- `PatternList.tsx` でカテゴリ別一覧表示、`PatternDetail.tsx` で詳細表示
  - 名称・特徴・優先度目安・回答骨格・対応ポイントを表示
- `explanationPatternLinks.tsx` で explanation 中の「パターンN」をリンク化
  - 正規表現で抽出し、存在するIDのみ `#/patterns/:id` へ遷移
  - 危険なHTML挿入は使わずテキストレンダリングで安全性を維持

### PBI-054: ExamResult前後問導線（ストレッチ）

- `ExamResultView.tsx` 詳細パネルに「前の問へ/次の問へ」を追加
- 先頭・末尾で `disabled` + `aria-disabled` を適用
- 遷移後に新しい詳細見出しへフォーカス移動し、キーボード利用の連続閲覧性を改善
- Escape/「結果一覧に戻る」導線は既存仕様を維持
- `ExamResultView.back.test.tsx` で前後遷移・端境界・フォーカス遷移を検証
