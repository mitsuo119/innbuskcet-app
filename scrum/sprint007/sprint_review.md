## 1. インクリメントのデモ（伊藤・田中）

### 1-1. 学習フロー全体（Quick / Deep / Exam）

1. ヘッダー右上のセグメントコントロール `[Quick(5分) | Deep(じっくり) | Exam]` で学習スタイルを 1 タップ切替。Sprint006 までグレイアウトだった Exam が本実装で活性化。
2. **Quick / Deep**: Sprint006 完了の現行フロー継続（PBI-036 / PBI-037 / PBI-035）。
3. **Exam（新規）**: Toggle で Exam 選択 → 確認モーダル「Examモード: 20問・90分タイマーが開始されます。よろしいですか？」 → 90 分タイマー起動 → 20 問固定ランダム出題（Quick/Deep 履歴非汚染）→ 中断ボタン or 時間切れで自動終了。
4. **AI 評価フィードバック（新規）**: Deep モードで 3 ブロック記述後「AI に見てもらう」ボタン → ルールベース評価ロジックが観点別（5W1H/委任/フォロー/関連）と総合（判断/理由/アクション）を ◎/○/△ で表示。

### 1-2. PBI-027: 時間制限モード（20問90分・Exam）基本機能（伊藤・田中・山本・中村）

- `domain/examTimer.ts` 新設：`createExamSession` / `getRemainingSeconds` / `isTimeUp` / `formatTime` / `saveExamSession` / `loadExamSession` / `clearExamSession` の純粋関数 + sessionStorage I/O。`Date.now()` ベースで `startedAt` を記録（タブ非表示でも実時間継続）。`examTimer.test.ts` 20 件 PASS（境界値・ラウンドトリップ・不正 JSON / 型不一致・必須キー欠落フォールバック / DoD §10-1・§10-3）。
- `LearningStyle` 型に `'exam'` 追加・`LEARNING_STYLES.exam` 定義・Toggle のグレイアウト解除（PBI-036 連動・順序 ORDER に exam 追加）。
- `ui/ExamTimer.tsx` 新設：`role="timer"` / `aria-label="残り時間"` / `aria-live="polite"`・mm:ss 常時表示・残 5 分以下で `--warning` 修飾子＋「残りわずか」テキスト併記（DoD §9-2 色非依存）・`setInterval` 毎秒更新＋ `useEffect` クリーンアップ・`onTimeUp` は残 0 秒で一度のみ呼出（fakeTimers テスト 7 件で機械検証）・`dangerouslySetInnerHTML` 不使用（DoD §10-2）。
- `App.tsx` 結線：`examSession` / `examIndex` 状態を追加し、Exam モード時は `examSession.questionIds` を順次消費する出題ループへ切替。`handleNext` で末尾到達時は `finalizeExamSession` で Deep へ復帰。Quick/Deep 履歴は従来どおり `pickNextCaseByMode` 経路のみ加算され、Exam ループは `allCases.find` 直接参照でセット独立を確保（PBI-037 整合）。
- 中断機能：Exam 中の Toggle 切替時に `window.confirm("Examを中断します。進捗は失われます。よろしいですか？")` → OK で `clearExamSession` + state リセット → Deep 復帰。
- 時間切れ自動終了：`ExamTimer.onTimeUp` から `handleExamTimeUp` → `finalizeExamSession` で `alert("時間終了！お疲れ様でした。")` 発火。未回答案件はカウンタ非加算でセット結果は正答率＋所要時間を案内。
- a11y：NVDA 実機で「Toggle → 確認モーダル → タイマー開始 → 残り 5 分警告読み上げ」経路を確認（`a11y_checklist.md` 6-B セクション 3-20〜3-23 記録）。
