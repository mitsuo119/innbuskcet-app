# 依頼事項メモ order008

## 依頼者

顧客: 佐藤

## 依頼概要

スマートフォン表示において、モードボタンとサブタイトルテキストが重なって表示されており、視覚的に見づらい状態になっている。ボタンとテキストの間隔を適切に調整してほしい。

## 問題の詳細

- タイトル「インバスケット」の直下に Quick / Deep / Exam / ライト のモードボタンが表示されている
- モードボタンの下に「インバスケット学習アプリ」というサブタイトルテキストが表示されている
- スマートフォン画面では、「インバスケット学習アプリ」テキストとモードボタン群が重なる、もしくは隙間なく並んでおり、視覚的に非常に見づらい
- PCブラウザでは問題ないが、モバイル（スマートフォン）での表示に限定した問題の可能性あり

## 要求事項

- モードボタン群（Quick / Deep / Exam / ライト）と「インバスケット学習アプリ」サブタイトルテキストの間に適切な余白（マージン・パディング）を設けること
- スマートフォン画面サイズ（特に小〜中サイズ）でレイアウトが崩れないよう修正すること
- 修正後はモバイルブラウザで視覚的に確認すること

## 補足

- 対象画面: アプリのトップ画面（ホーム画面）
- 再現環境: スマートフォンブラウザ（モバイル表示）
- レスポンシブデザインの見直しが必要な箇所と思われる
- 優先度は高め（ユーザーが最初に触れる画面のため、第一印象に直結する）
