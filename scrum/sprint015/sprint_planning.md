## トピック1: Why（スプリントゴール）

### ゴール策定の議論

**高橋（SM）**: Sprint014 で主軸3PBI（PBI-061/062/063）を計画通り完了し UI 品質を底上げできました。今回はリファインメントで Ready 化された PBI-065（1pt, High）を最優先で取り込みます。一般公開ユーザに対しブランド名と未完成印象を払拭する小粒だが価値の明確なスコープです。

**伊藤（Dev）**: PBI-065 は変更点が `App.tsx` ヘッダー / `index.html` `<title>` / 既存テストの文字列追従に局所化されます。先に PO・開発者間でサブタイトル文言を確定させれば Day1 で実装〜テスト追従まで完結できます。

**田中（Dev）**: ロゴ/ファビコン差替えは対象外、法務ページ等本文中の固有名「InBusket」もスコープ外と明示されているので、過剰拡張せず DoD 21項目の通過に集中します。

### スプリントゴール（確定）

> **「一般公開ユーザに対しアプリブランドを日本語（インバスケット）で正しく伝え、UI 上から未完成印象を与える内部表記（MVP 開発中・Sprint 番号）を払拭する」**

- PBI-065 を主軸として確実に Done させる
- ストレッチで PBI-064（ナビゲーション一貫性）を Day3 時点の余力判定で投入検討
- 全員合意: 鈴木 ✓ / 伊藤 ✓ / 田中 ✓
